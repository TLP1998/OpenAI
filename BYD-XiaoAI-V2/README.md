# 小破车 × 超级小爱 V2.2 — 三项语音车控

基于 [fm1223/byd-android](https://github.com/fm1223/byd-android) 固定源码提交构建。本项目非比亚迪官方授权。第三方逆向协议、WBSK 相关授权存在不确定性，不要将登录凭据公开。

## 重要：上一个 V2 版本无法覆盖升级
每次 GitHub Actions Debug APK 可能使用新的随机本机签名。请**先卸载旧 V2 车控主程序及两个旧版语音入口**；重新安装本次全部四个 APK。原版车辆助手可保留。卸载旧主程序会删除其保存的登录会话与 PIN，需要在 V2.2 重新配置。

## 本次四个 APK
1. `byd-voice-core-debug.apk` — 比亚迪车控主程序（登录、车辆、操作 PIN）
2. `xiaopoche-lock.apk` — 小破车上锁（只上锁）
3. `xiaopoche-unlock.apk` — 小破车解锁（解锁）
4. `xiaopoche-lock-closeair.apk` — 小破车上锁并熄火（先上锁，再尝试原源码 CLOSEAIR）

建议小爱口令：
- **“小爱同学，打开小破车上锁APP”**
- **“小爱同学，打开小破车解锁APP”**
- **“小爱同学，打开小破车上锁并熄火APP”**

## 操作机制
- **不再设置45秒冷却间隔**。不过单个语音启动只发送一次，同一时间车控任务进行中，不再并发执行新的请求；网络失败或服务器返回结果未知时也不会自动重试。
- 上锁与解锁无需再弹出额外指纹认证。
- 锁屏/息屏时，App 尝试使用安卓 `showWhenLocked` / `turnScreenOn` 处理语音启动；是否能由超级小爱从锁屏实际唤起，仍由 HyperOS 系统权限控制，**不能保证**。
- 上锁并熄火严格按顺序执行：仅当服务端明确返回上锁成功，才发送第二条命令。否则不发送第二条，以免状态不明确时执行。
- **原代码的“熄火”命令 `DoorAction.SHUTDOWN` 实际对应 `CLOSEAIR`，属于关闭空调/车内空调系统的远程操作，不应理解为已验证的发动机熄火或整车下电。**
- 不使用巴法云后台联动。仅通过本地安装 App 入口 + 比亚迪云协议进行车控。

## 物理安全风险
**没有每次身份认证的锁屏语音解锁，会使附近任何能够唤起小爱的声音有机会打开车辆。** 语音识别本身并不验证车主身份。只有在你能控制电话的物理与语音环境时才建议测试。可随时卸载「小破车解锁」语音入口来关闭这个风险通道。
首次实车测试请到车旁、静止安全环境，确认车辆内部无人或宠物。不要把锁车并关闭空调用于车内有人的场景。
