# BYD × XiaoAI V2 — 语音锁车/解锁（个人实验版）

本项目在 `fm1223/byd-android` 的协议实现上加入小爱唤起入口。只需要**手机本地 + 比亚迪云服务**，不使用巴法云，也不需要小爱开发者账号。

## APK 安装顺序（3 个包）
1. 卸载先前的两个 V1 入口 App「比亚迪锁车测试」「比亚迪解锁测试」；原版车辆助手可保留。
2. 安装 **byd-voice-core-debug.apk**：名称为「比亚迪车控主程序」，与原版并存但账号存储不共享。
3. 打开车控主程序，按原车助手流程登录、选择目标车辆，并在「设置」中验证、保存六位操作 PIN。不要在聊天中发送账号、密码或 PIN。
4. 安装 **byd-voice-lock-debug.apk**、**byd-voice-unlock-debug.apk**。
5. 对小爱说：「打开比亚迪锁车测试APP」「打开比亚迪解锁测试APP」。

## 行为
- 锁车：打开语音入口后，**自动向比亚迪云发送真实锁车指令**，不附带熄火，45 秒内相同指令只接受一次；不会自动重试。
- 解锁：打开语音入口后，先弹出安卓系统指纹/锁屏凭证认证，通过才执行真实解锁；取消则不执行。
- 不保存任何账号密码在两个语音入口 APK 内，所有凭证只在「车控主程序」通过 Android Keystore 加密。
- 与原车辆助手**不同包名**，需要在主程序里重新登录一次。
- 语音入口使用仅允许同签名 APK 的受保护 Activity，不能被任意第三方 App 直接启动。
- 云端操作不等同于实时门锁状态：结果未知时请现场核实，不要重复触发。
- 本批次采用 GitHub Actions **临时 Debug 签名**，未来重新编译后，可能需要卸载旧测试 APK 才能安装新版；后续应改为持久签名。

## 安全前提
第一次实车测试前，将车辆停在安全位置，站在车旁现场观察；确认车内无人员或宠物，车辆已熄火。不要在行驶过程中尝试远控。不要把没有二次认证的解锁交给智能体。
