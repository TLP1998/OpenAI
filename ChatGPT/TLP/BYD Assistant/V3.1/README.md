# V3.1 · 小笛车控助手（单 APK、单桌面图标、可修改口令）

这版针对 V3 的实机反馈改造：同一个 APK 里的多个启动图标，虽然 Android 支持，但超级小爱没有正确区分。**V3.1 只注册一个桌面图标。**

## 下载、安装
- [GitHub V3.1 Release](https://github.com/TLP1998/OpenAI/releases/tag/byd-xiaoai-v3-1)
- 文件：`xiaodi-voice-v3.1.apk`
- 包名：`dev.vehiclebridge.byd.xiaoai.v31`（可与 V2.2 / V3 并存；不共享账号登录状态）
- 推荐先**保留 V2.2**，等 V3.1 在小米15验证成功后再清理旧应用图标。

## 主要功能
- 一个应用「**小笛车控助手**」，**只有一个 Launcher/桌面图标**。
- App 内可编辑、保存、重新读取三条语音口令：
  1. 上锁：`小笛锁车`
  2. 解锁：`小笛解锁`
  3. 上锁并关闭空调：`小笛锁车熄火`
- 每条口令可更改为 2～24 个中文、英文或数字字符，三条不得重复；匹配时忽略空格和标点，但必须**整句一致**，不会拿「锁车」子串误触发「解锁」。
- 内置「开始说指令」按钮，通过 Android 系统 `RecognizerIntent.ACTION_RECOGNIZE_SPEECH` 获取语音文字。**使用的是手机上的语音识别服务，可能需联网，可能显示系统录音对话框**。
- 可勾选「打开 App 时自动进入语音识别」，下次打开时自动弹出语音识别界面；由于小米超级小爱本身也可能正在使用麦克风，能否流畅衔接要在小米15上验证。
- 保留原车辆助手的登录、PIN、手动车控功能，主界面按钮进入。
- 45 秒冷却已删除；仍不并发重复执行，结果未知时不自动重试；不使用巴法云。
- 「小笛锁车熄火」中的第二条远控为原协议 `CLOSEAIR` **关闭空调请求**，并不保证真正熄火或整车下电。

## 小爱如何使用？
1. **「小爱同学，打开小笛车控助手APP」**：小爱只负责打开**一个 App**。
2. App 自动打开语音识别界面（需先开启 App 内的自动识别选项），你接着说：「小笛锁车」等自定义口令。
3. 若不启用自动识别，打开 App 后点击「开始说指令」。

> **重要限制：这是两段语音交互，不是由小爱在同一句话中直接调用私有车控 API。** App 内口令设置不能把新口令自动注册为小爱的技能、快捷指令或唤醒词。想实现原目标“一句话直接执行”，仍需找到经过验证的 Xiaomi 系统快捷方式/开放接口；V3.1 不宣称已实现。

## 安全和兼容性
- 语音解锁**不进行每次身份确认**，如果手机/超级小爱允许锁屏下启动，其他人也可能说出相同口令并打开车门。当前 App 并不验证声纹，需自行控制使用场景。
- App 在锁屏上显示的能力不等于系统语音识别能够在锁屏下完成；HyperOS 可以限制该行为。
- 主程序保存比亚迪凭证时沿用原源码的 AndroidKeystore 加密。App 内自定义口令只保存在手机本地 `SharedPreferences`，不是车控密钥。
- 没有使用巴法云或自建云服务，仅调用基于 [fm1223/byd-android](https://github.com/fm1223/byd-android) 的非官方比亚迪中国区私有协议。
- 测试时请站在车辆旁、车内无人时执行；车锁服务器反馈不代表已读取实时门锁状态。
