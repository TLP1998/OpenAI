如何验证沙箱是否能够访问 Cloudflare Worker？

消息编号：TLP-20261016-001 · 2026-10-16 · 系统测试 / 网络连通性

可以直接在公司沙箱浏览器中验证，不需要安装软件、登录账号或修改电脑配置。需要区分两件事：能否访问 Worker HTTPS 地址以及是否允许向该地址发送 HTTPS POST 请求。

第一步：初步验证网络可达

在沙箱浏览器中打开 https://workers.cloudflare.com/。

如果网站能够打开，只能说明 Cloudflare Workers 官方网站至少部分可访问；不能证明 *.workers.dev 域名或实际 Worker 接口可以访问。

下一步需要使用一个实际部署的 Worker 测试地址。由于目前尚未部署专用测试 Worker，不能把形如 https://tlp-test.某账号.workers.dev 的示例地址当作有效接口。

第二步：验证能否发送非敏感文字

待专用测试 Worker 实际部署后，通过经批准的测试页面发送一条不含敏感内容的消息，例如：

TLP Transfer 网络连通性测试

点击「发送测试」，检查接口返回值；建议测试服务只回显状态，不存储数据。

结果说明
返回 200 OK测试接口响应成功，具备进一步实施条件；仍需核实实际发送内容和网络策略
网页可打开，POST 失败可能有提交请求限制或接口配置问题
返回 403 Forbidden可能被网络访问策略或服务器权限设置拒绝
连接超时、网站被拦截可能存在网络策略、DNS 或连接问题
浏览器提示 CORS 错误可能是接口跨域配置问题，不能直接判定为网络封锁

接下来如何操作？

先在公司沙箱访问 Cloudflare Workers 官网，反馈「可以打开 / 被拦截 / 一直加载失败」。如果可达，再创建一个真实的、只用于非敏感内容验证的 Worker 接口，进一步测试 GET 和 POST。任何进一步网络访问应符合公司批准的范围。

本消息为公开的网络测试说明，不包含公司内部资料，也不提供绕过网络限制的方案。查看关联 GitHub 回复主题 #2。
