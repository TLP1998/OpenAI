DevSpace Windows 11 部署指南

消息编号：TLP-20261018-001｜2026-10-18

第一步：运行 Bootstrap

下载 TLP-DevSpace-Bootstrap-Win11.ps1，在 Windows 11 上按提示确认所需软件安装。完成后进入 DevSpace 初始化流程。

安装脚本：下载 PowerShell 脚本

PowerShell 运行命令

将安装脚本下载到 Windows 11 的「下载」文件夹后，打开 PowerShell，依次运行：

cd "$env:USERPROFILE\Downloads"
Set-ExecutionPolicy -Scope Process Bypass
.\TLP-DevSpace-Bootstrap-Win11.ps1

第二行仅对当前 PowerShell 进程生效。运行前请确认脚本来源与内容，按提示决定是否安装软件。

安全注意

不要将 DevSpace Owner 密码发送给 ChatGPT，也不要把整个 C 盘设为允许访问的工作目录。优先采用独立低权限账户与限定项目目录。

第二步：验证远程连接

安装成功后配置 HTTPS 隧道，再使用 ChatGPT 的「添加自定义 MCP 服务器」连接 DevSpace。

验收目标

  1. V1：Windows 11 基础环境和 DevSpace 安装成功。
  2. V2：ChatGPT 成功读取指定的本地测试文件。
  3. V3：ChatGPT 远程执行测试命令并读取结果。

先完成 V1，运行后将 PowerShell 最后一屏截图发回 TLP 项目聊天。

查看 GitHub Issue 与在线回复 · DevSpace 项目源码

安装故障排查｜PowerShell 窗口自动关闭

右键「使用 PowerShell 运行」后窗口消失，不能据此判断安装成功。请先打开 Windows 终端或 PowerShell，保持窗口不关闭，再复制下面整段命令执行：

$script = Join-Path $env:USERPROFILE "Downloads\TLP-DevSpace-Bootstrap-Win11.ps1"
Write-Host "检查脚本文件：$script"
if (Test-Path -LiteralPath $script) {
    Write-Host "已找到脚本，准备执行。"
    powershell.exe -NoProfile -ExecutionPolicy Bypass -File $script
    Write-Host "脚本退出代码：$LASTEXITCODE"
} else {
    Write-Host "错误：未找到脚本文件，请检查下载位置。"
}
Read-Host "按回车键关闭检查"

若脚本不在 Downloads，请将路径改成实际保存位置。执行前检查脚本来源与内容；暂时不要反复右键运行。

检查环境

node --version
npm --version
git --version
npm list -g @waishnav/devspace

注意：原 Bootstrap 通过 npx 运行 DevSpace，故全局 npm 列表显示 (empty) 并不必然表示初始化失败。

请将 PowerShell 中第一条红色错误信息及最后一屏结果截图发回 ChatGPT TLP 项目，以便进一步修复。不要分享 Owner 密码或 auth.json。
