DevSpace Windows 11 部署指南

消息编号：TLP-20261018-001｜2026-10-18

第一步：运行 Bootstrap

下载 TLP-DevSpace-Bootstrap-Win11.ps1，在 Windows 11 上按提示确认所需软件安装。完成后进入 DevSpace 初始化流程。

安装脚本：下载 PowerShell 脚本

PowerShell 运行命令

将安装脚本下载到 Windows 11 的「下载」文件夹后，打开 PowerShell，依次运行：

cd "$env:USERPROFILE\Downloads"
Set-ExecutionPolicy -Scope Process Bypass
.\TLP-DevSpace-Bootstrap-Win11.ps1

第二行仅对当前 PowerShell 进程生效。运行前请确认脚本来源与内容，按提示决定是否安装软件。

安全注意

不要将 DevSpace Owner 密码发送给 ChatGPT，也不要把整个 C 盘设为允许访问的工作目录。优先采用独立低权限账户与限定项目目录。

第二步：验证远程连接

安装成功后配置 HTTPS 隧道，再使用 ChatGPT 的「添加自定义 MCP 服务器」连接 DevSpace。

验收目标

  1. V1：Windows 11 基础环境和 DevSpace 安装成功。
  2. V2：ChatGPT 成功读取指定的本地测试文件。
  3. V3：ChatGPT 远程执行测试命令并读取结果。

先完成 V1，运行后将 PowerShell 最后一屏截图发回 TLP 项目聊天。
