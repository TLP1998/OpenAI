Node.js v22.19.0｜Windows 10 安装包与环境验证

TLP-20261018-004｜2026-10-18

针对 Windows 10 专业版 22H2（19045），建议先使用 Node.js v22.19.0 的 Windows x64 MSI。它符合 DevSpace 的 Node 版本范围，但尚未在你的电脑上实测。

官方安装包

下载 Node.js v22.19.0 Windows x64 MSI

查看 Node.js 官方版本归档

安装包作为外部下载附件提供，由 Node.js 官网托管；未将二进制文件复制到公开 GitHub 仓库。

安装后检查

完成安装后关闭 PowerShell，重新打开并运行：

node --version
npm.cmd --version
git --version

预期 Node.js 显示 v22.19.0，npm 和 Git 显示版本号。请将结果截图发回 TLP 项目聊天，继续 DevSpace V1 验收。

不要分享 DevSpace Owner 密码或令牌，也不要开放整个 C 盘。
