消息与回复管理

删除通过 GitHub 网页手动操作：先打开对应的 Issue 或评论，再以有权限的 GitHub 账号删除。完整消息还需单独清理 HTML、附件及中转站索引。本站不存储登录凭证，也不会自动删除。

粘贴完整 GitHub 评论链接，可跳转定位；删除需要有权限的 GitHub 账号。

删除操作执行后可能无法恢复。请核对目标与专属附件；删除 Issue 不会自动删除中转站 HTML 和索引，关闭 Issue 不等于删除。
收件箱
支持在消息或回复上长按 / 鼠标右键打开管理菜单。直接删除需要在私人设备上输入受限 GitHub Token；本页不保存 Token，不要在公司沙箱输入个人授权信息。仅用于发布经许可公开的非敏感内容。网页及 GitHub Issue 评论均为公开信息。阅读无需登录；发表评论需登录 GitHub，密码由 GitHub 处理，本网站不保存密码。请遵守公司外发及沙箱使用规定。
